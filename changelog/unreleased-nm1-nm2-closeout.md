# NM-1/NM-2 closeout

The owner authorized closing the original NM-1/NM-2 gates before further NM-3
development. Existing NM-3 branches, behavior and evidence are preserved.

Signed future approval/contract schemas and an unknown envelope version are
explicitly rejected before contract consumption. This strengthens existing
conformance proof without changing the validator or wire format.

Agent guidance and ADR 0016 now recognize the explicitly enabled managed Compose
worker authorized by New Moon. Defaults and legacy commands remain unchanged.
No worker or Linux containment is activated, and no added privilege or new
service is authorized by this documentation change.
