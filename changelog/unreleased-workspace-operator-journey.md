# Workspace operator journey

Add `workspace authority-init`, `workspace authorize` and `workspace execute`.
The operator provisions private local trust, reviews one exact fixed-Gate plan,
approves its finite credential references, and issues the existing signed
single-use contract without hand-authoring permission contexts. Execution and
optional export reuse the existing native consumer, journal and redacted export.

Issuer keys stay outside execution state and never enter the six-document public
bundle or exports. Container packaging must preserve this separation. Existing
connected commands, explicit file interfaces and unsupported-platform refusal
remain unchanged. This increment alone does not provide a recon executor or
qualify cross-platform packaging.

New bundle consumers reconstruct the original workspace/Runner/issuer/public-key
metadata hash before consumption. A self-signed replacement key cannot reuse an
existing local authority digest. Legacy explicit reference-trust inputs keep their
existing meaning.
